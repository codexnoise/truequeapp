# Migración Flutter 3.38.1 → 3.44.9 — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Llevar TruequeApp de Flutter 3.38.1 (Dart 3.10.0) a Flutter 3.44.9 (Dart 3.12.x) manteniendo Android e iOS compilando y funcionando en dispositivo real, adoptando Swift Package Manager en iOS y sin tocar el tooling de Android ni las versiones de paquetes de pub.

**Architecture:** La migración es de SDK/tooling, no de features. Se pinnea la versión con FVM (`.fvmrc`), se deja que el CLI de Flutter 3.44 aplique sus migradores automáticos de iOS (UIScene lifecycle + integración SwiftPM), se retira CocoaPods del proyecto Xcode, y se valida con la suite de tests existente, builds release de ambas plataformas y smoke test en el iPhone 17 físico y el emulador Android 17. Cada tarea deja el repo en estado compilable y se commitea por separado.

**Tech Stack:** Flutter 3.44.9 / Dart 3.12, FVM 4.1.0, Xcode 26.5, CocoaPods 1.16.2 (solo para desintegrar), AGP 8.11.1 + Kotlin 2.2.20 + Gradle 8.14 + Java 17 (sin cambios), Firebase (firebase_core 4.4.0 y plugins), Riverpod 3.1, go_router 17.

## Rollback

En cualquier punto: `git checkout develop && fvm use 3.38.1 && fvm flutter clean && fvm flutter pub get`. Todo lo que tocan las tareas está versionado (incluida la desintegración de CocoaPods, que se revierte con el checkout). `~/fvm/versions/3.44.9` puede quedar instalado sin afectar a `develop`.

## Riesgos conocidos
- **Descarga de `firebase-ios-sdk` por SwiftPM** en el primer build iOS: lenta y sensible a red (corregido en 3.44.2/3.44.3; reintentar el mismo comando).
- **Xcode abierto durante los migradores** (Task 5): puede pisar `project.pbxproj`/workspace. Cerrarlo antes.
- **Build de la app instalada con cuenta Apple gratuita** expira a los 7 días; no afecta a la migración.
- **Colores M3** (Task 8): cambio visual sutil en `onErrorContainer`; decisión por defecto = aceptar.

## Siguiente paso después de este plan
Migración a 3.47.x (estable actual 3.47.5): AGP 9 obligatorio + built-in Kotlin (`android.builtInKotlin=true`) — al subir a AGP 9 hay que **flipear a `true` o eliminar** `android.builtInKotlin=false` y `android.newDsl=false` de `android/gradle.properties` (las escribió el migrador de 3.44 para fijar los defaults de AGP 8; si quedan en `false`, el proyecto seguiría optando por los defaults viejos), iOS mínimo 15 (ya cumplido: el proyecto está en 15.0), macOS 12 (N/A), Material/Cupertino desacoplados como paquetes opt-in (`dart fix --apply --code=migrate_design_widgets`, deprecación formal prevista para 3.50). Investigación preliminar hecha en esta misma sesión; se planifica sobre la base que deja este plan.
